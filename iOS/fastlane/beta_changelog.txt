0.4.5 (build 150) — fixes the dead space at the top of the Status screen.

The cairn wordmark sat about 65pt lower than intended on every screen with the brand header (Status and Setup), leaving a conspicuous empty band above the fold. The padding was adding the status bar height to content that iOS had already pushed below the status bar, counting it twice.

Everything from build 149 is included: trash-queue reliability, no more duplicate runs for the same photos, and Immich v3 incremental sync.

To test: open the app and check that the wordmark sits a normal distance below the status bar rather than a third of the way down the screen. Worth a look on the Setup screen too if you have a spare device or a fresh install — it uses the same header. If you haven't exercised build 149 yet, the notes there still apply: queued trash requests should drain or drop rather than sticking, and a batch you trash should produce exactly one run in the list.
