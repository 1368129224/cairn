0.4.5 (build 151) — optionally keep your server setup through a phone upgrade.

New toggle at Settings → Connection → "Include credentials in backups", off by default.

cairn stores your Immich server address and API key in the iOS Keychain, sealed to the device they were entered on. That seal also excludes them from encrypted backups and from device-to-device transfer, which is why upgrading a phone has always dropped you back on the setup screen no matter how you migrated. Turning the toggle on lifts the seal, so they restore along with an encrypted backup.

- This is backup only. It does not sync credentials between your devices — an iPad and an iPhone still each need setting up.
- Your Immich session token (if you've signed in for incremental sync) stays device-only either way.
- Turning it back off re-seals things going forward, but doesn't remove credentials from backups already taken.

To test: flip it on in Settings → Connection and confirm cairn keeps working normally — the toggle rewrites the stored credentials in place, so the immediate check is simply that syncing, trashing and the Runs list all still behave. Rotating your API key afterwards (API key row → Replace) is worth a try too: the setting should stay on and keep applying. The real proof needs an encrypted backup and a restore onto another device, so only worth it if you're doing one anyway.
